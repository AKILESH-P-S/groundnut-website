# 🌱 Groundnut Shelling and Oil Extraction Machine Website

This project is a responsive web-based dashboard and information website developed for a Groundnut Shelling and Oil Extraction Machine. The website is designed to display machine details, production status, real-time monitoring data, and project information.

## 🚀 Project Overview

The Groundnut Processing Machine is developed to automate the shelling and oil extraction process with improved efficiency, reduced manual effort, and real-time production monitoring.

This website acts as:

* Project presentation platform
* Production monitoring dashboard
* Machine information portal
* Portfolio showcase

## 🎯 Features

✅ Machine Overview Section
✅ Real-time Production & Stock Dashboard (Future Integration)
✅ Sensor Data Monitoring (Temperature, RPM, Production Count)
✅ Image Gallery of Machine Development
✅ Contact Form Integration
✅ Responsive Design for Mobile and Desktop
✅ Clean UI with Dark Theme

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Web3Forms (for contact form API)
* GitHub Pages / Netlify (for deployment)

## ⚙️ Machine Technical Highlights

* Motor Speed Controlled from **1440 RPM to 300–350 RPM** using pulley/VFD system
* Groundnut Shelling Roller Mechanism
* Oil Extraction Heating Process for 1 Kg Batch
* Frame Designed using Mechanical CAD Tools
* Future Integration with **IoT Dashboard & Predictive Maintenance System**
